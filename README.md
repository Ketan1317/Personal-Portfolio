# Ketan Goyal — Portfolio

A modern, interactive portfolio showcasing my projects, technical skills, and journey as a full-stack developer. Built with a focus on clean design, immersive 3D visuals, smooth animations, and performance.

## Features

- Interactive 3D project showcase
- Smooth animations and scroll effects
- Dark and light themes
- Responsive, accessible design
- GitHub activity and developer profiles
- Contact form for collaborations and opportunities

## Tech Stack

Next.js · TypeScript · Tailwind CSS · GSAP · Motion · Three.js · React Three Fiber

## Getting Started

```bash
git clone https://github.com/Ketan1317/ketan-portfolio.git
cd ketan-portfolio
pnpm install
pnpm dev
```

Open `http://localhost:3000` to explore the portfolio locally.
